# T0 Project 规则记忆

快照日期：`2026-04-12`

## 1. 宪法级规则
- `t0_project` 不接管 `daily_research` 的正式执行默认值。
- 盘中实验结果必须被视为实验结论，不得越级写成生产结论。
- 接管先读身份层与交接包，不得先盲扫策略代码。

## 2. 策略级规则
- 当前默认进入顺序：
  - `identity -> handoff packet -> semantic -> rule -> lesson -> temporal -> working -> action`
- 执行接入顺序固定为：
  - `paper -> 人工确认 -> 真实接口`
- 真实自动交易接口上线前，先把抽象层、风控层和适配器能力补齐。

## 3. 经验级规则
- `live` 当前是保护性骨架，不是 bug，也不是已打通能力。
- RL 当前只适合作为回放 / `paper` 验证链路的一部分。
- 若某结论可能影响正式生产主线，必须回到主脑和 `daily_research` 分脑复核。
