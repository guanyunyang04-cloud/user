基础说明
- 以下命令默认在目录 h:\new_tdx64\PYPlugins\user 下执行
- 如使用 conda 环境 yolos，可先运行：conda activate yolos

1. 运行主策略：日线选股 + 盘中做T
python t0_project/integrated_tq_strategy.py

2. 运行主策略并关闭大盘风控
python t0_project/integrated_tq_strategy.py --no-market-risk

3. 运行主策略并推送更少股票
python t0_project/integrated_tq_strategy.py --top-k 20

4. 调整主策略盘中轮询频率
python t0_project/integrated_tq_strategy.py --check-interval 5

5. 调整主策略建仓/加仓目标仓位
python t0_project/integrated_tq_strategy.py --entry-position-ratio 0.12 --add-position-ratio 0.04

6. 开启调出股票池后的减仓/清仓处理
python t0_project/integrated_tq_strategy.py --sell-if-out-of-pool

7. 运行一次专用选股脚本，不推送
python t0_project/select_stocks_only.py

8. 运行一次专用选股脚本，并推送到通达信板块
python t0_project/select_stocks_only.py --push-block --target-tdx-block 威科夫共振

9. 运行一次专用选股脚本，并导出 CSV
python t0_project/select_stocks_only.py --top-k 20 --output-csv t0_project/output/selection.csv

10. 按指定日期运行一次专用选股脚本
python t0_project/select_stocks_only.py --as-of-date 20230703 --top-k 20 --show-top 20

11. 按指定日期运行一次专用选股脚本，并导出 CSV
python t0_project/select_stocks_only.py --as-of-date 20230703 --top-k 20 --output-csv t0_project/output/selection_20230703.csv

12. 运行手工做T监控器，使用文件内默认持仓
python t0_project/my_t0_monitor.py

13. 运行手工做T监控器，并通过命令行传入持仓/观察股
python t0_project/my_t0_monitor.py --positions 601678.SH:5.50,600036.SH:36.20,601318.SH:none

14. 运行手工做T监控器，并调整止损止盈参数
python t0_project/my_t0_monitor.py --positions 601678.SH:5.50 --hard-stop-loss-pct 0.06 --tp1-pct 0.08 --tp2-pct 0.15

15. 小样本回测
python t0_project/backtest_integrated_strategy.py --stocks 600000.SH,600036.SH,601318.SH --start-date 20220101 --end-date 20231231 --top-k 3 --max-positions 3 --initial-capital 1000000 --pool-refresh-days 1

16. 20只股票样本回测
python t0_project/backtest_integrated_strategy.py --stocks 600000.SH,600036.SH,601318.SH,600519.SH,601166.SH,601398.SH,601288.SH,601988.SH,600030.SH,600809.SH,600276.SH,600887.SH,601012.SH,600900.SH,601088.SH,600690.SH,000001.SZ,000333.SZ,000651.SZ,002415.SZ --start-date 20220101 --end-date 20231231 --top-k 10 --max-positions 5 --initial-capital 1000000 --pool-refresh-days 1

17. 查看主策略帮助
python t0_project/integrated_tq_strategy.py --help

18. 查看手工监控帮助
python t0_project/my_t0_monitor.py --help

19. 查看专用选股脚本帮助
python t0_project/select_stocks_only.py --help

20. 语法检查
python -m py_compile t0_project/integrated_tq_strategy.py
python -m py_compile t0_project/my_t0_monitor.py
python -m py_compile t0_project/select_stocks_only.py
python -m py_compile t0_project/backtest_integrated_strategy.py

补充说明
- select_stocks_only.py 支持 --as-of-date YYYYMMDD 指定历史日期选股
- 若指定日期不是交易日，脚本会自动回退到最近一个交易日
- 若运行时报 TQ 初始化失败，通常是当前已有同名策略运行，或 TQ 端未准备好
