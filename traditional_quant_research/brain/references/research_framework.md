# Traditional Quant Research Framework

状态：accepted

日期：2026-06-02

适用范围：`traditional_quant_research` 的沪深主板普通 A 股传统量化研究。

## 定位

本项目的研究框架不是单纯的模型训练管线，而是一条从研究问题到可复验结论的完整链路。模型输入、模型架构、模型输出、loss 和执行只是其中的模型层与执行层；在传统量化研究中，数据口径、样本构造、因子定义、标签、组合构建、回测协议和证据分级同等重要，且通常更先决定结论是否可信。

默认研究闭环：

```text
研究问题
-> PIT 数据集
-> 样本构造
-> 特征/因子
-> 标签/目标
-> 模型或打分方法
-> loss/训练目标
-> 预测输出
-> 组合构建
-> 回测执行
-> 评估诊断
-> 实验记录
-> 结论分级
```

## 1. 研究问题层

每个实验先声明要回答的问题，而不是先选择模型。

典型问题：

- 沪深主板普通 A 股中，某类传统因子是否具有稳定横截面预测力。
- 未来 `1/5/20` 日收益能否被动量、反转、波动率、流动性或价量结构解释。
- 扣除交易成本后，信号能否形成稳定组合收益。
- 现象是否只存在于样本内，还是样本外仍然成立。

研究问题必须定义：

- 股票池与排除规则。
- 预测频率与预测 horizon。
- 调仓频率。
- 交易成本假设。
- 主要评价指标。
- 结论允许达到的证据等级。

## 2. PIT 数据集层

默认数据源是 v2 点时研究快照。研究代码只读项目快照 loader，不直接访问 Baostock 或 TDX。

默认 loader：

- `load_tradeable_panel()`
- `load_daily_universe(tradeable_only=True)`
- `load_pit_daily_bars()`
- `load_quality_report()`

数据集层必须提供：

- `snapshot_id`
- 样本区间。
- 每日点时股票池。
- 历史上市/退市状态。
- 历史 ST 状态。
- 历史停牌/不可交易状态。
- 日频 OHLCV 与成交额。
- 质量报告与已知数据限制。

任何正式研究结论必须引用 `snapshot_id` 和质量摘要。

## 3. 样本构造层

原始行情不能直接喂给模型。样本构造层负责把 panel 转成：

```text
(date, code, features..., label, masks...)
```

必须固定：

- 训练集、验证集、测试集切分。
- 是否滚动训练与滚动窗口长度。
- 是否只使用当日 `is_tradeable=True` 标的。
- 特征观测日与标签收益区间。
- 信号生成时间与成交时间。
- 停牌、ST、退市、缺失价格、零成交额的处理。

核心原则：因子在 `t` 日收盘后可知，最多用于预测 `t+1` 或之后的收益，不能使用未来信息。

## 4. 特征与因子层

传统量化优先从可解释因子开始，而不是直接堆复杂模型。

第一阶段因子族：

- 收益：`ret_1d`、`ret_5d`、`ret_20d`。
- 动量/反转：短期反转、中期动量。
- 波动率：`vol_20d`、振幅、下行波动。
- 流动性：成交额、成交量、成交额均值、换手 proxy。
- 价量结构：放量上涨、缩量下跌、量价背离。
- 趋势：均线偏离、均线斜率、突破和回撤。
- 风险暴露：市值、行业、beta 等后续补齐。

特征处理必须记录：

- winsorize 规则。
- 横截面标准化规则。
- 缺失值处理。
- 是否行业/市值中性化。
- 滞后规则。

## 5. 标签与目标层

标签定义决定模型学习的目标。

优先标签：

- `fwd_ret_1d`
- `fwd_ret_5d`
- `fwd_ret_20d`
- `fwd_excess_ret`
- 横截面收益 rank。
- top quantile 分类标签。

早期建议以横截面排序和超额收益为主，不把绝对收益点预测当成唯一目标。

## 6. 模型层

模型层包括模型输入、模型架构、模型实现、模型输出和训练目标，但它不是研究框架的全部。

推进顺序：

1. 无模型基线：单因子 IC、分组收益、多因子等权打分、排名选股。
2. 传统机器学习：线性回归、Ridge、Lasso、Logistic、树模型、LightGBM/XGBoost、排序模型。
3. 复杂模型：深度学习、时序模型、Transformer 等仅在基线有效且问题需要时引入。

默认模型输入：

```text
features panel + universe mask + tradeable mask + labels + split ids
```

默认模型输出：

- 预测收益。
- 横截面 score。
- rank。
- top quantile 概率。
- 风险调整后的 alpha score。

模型输出不直接等于交易指令；交易指令由组合构建层生成。

## 7. Loss 与训练目标层

loss 必须服务于交易目标。

可选目标：

- 收益回归：MSE、Huber。
- 涨跌或分位分类：BCE、交叉熵。
- 横截面排序：pairwise/listwise ranking loss。
- 组合效用：收益减成本、风险调整收益、近似 Sharpe。

早期优先使用 IC、RankIC、分组收益和净值回测作为诊断指标，不急于设计复杂 loss。

## 8. 组合构建层

模型 score 需要转换为持仓权重。

基线组合：

- Top-N 等权多头。
- Top quantile 多头。
- Top-Bottom 多空。
- score 加权多头。
- 波动率缩放组合。

约束项：

- 单票权重上限。
- 行业或风格上限。
- 最大持仓数量。
- 换手率约束。
- 现金处理。
- 不可交易标的处理。

组合层必须与模型层分开评估，避免把组合规则收益误判为模型能力。

## 9. 回测与执行层

回测协议必须像真实交易一样处理时间和交易约束。

必须声明：

- 信号生成时间。
- 成交时间：次日开盘、次日收盘或其它约定。
- 调仓频率。
- 手续费。
- 滑点。
- 停牌处理。
- 涨跌停处理。
- ST/退市处理。
- 基准。
- 是否允许做空。

默认原则：收盘后生成信号，下一可交易日执行；不可交易标的不参与买入，已持仓不可卖出时按停牌约束处理。

## 10. 评估诊断层

不能只看最终收益曲线。

默认评价指标：

- IC / RankIC。
- ICIR。
- 分组收益单调性。
- 多空收益。
- 年化收益。
- 波动率。
- Sharpe。
- 最大回撤。
- 换手率。
- 胜率。
- 年度稳定性。
- 样本外表现。
- 成本敏感性。
- 极端行情分段表现。

如果一个信号只有回测收益好，但 IC 不稳定、分组不单调、换手过高，不能升级为强结论。

## 11. 实验记录层

每个实验必须留下可复验记录。

最低记录项：

- `snapshot_id`
- 数据区间。
- 股票池规则。
- 特征列表。
- 标签定义。
- 样本切分。
- 模型参数。
- 组合规则。
- 成本假设。
- 结果摘要。
- 失败原因。
- 下一步。

实验入口放在 `experiments/`，结论和复盘写入 `research_log/`。

## 12. 结论分级层

研究结论按证据强度分级：

- `idea`
- `diagnostic`
- `backtest_only`
- `out_of_sample_supported`
- `production_candidate`

早期大多数结果只能是 `diagnostic` 或 `backtest_only`。只有通过样本外、成本、稳定性和异常行情检验后，才允许升级。

## 当前第一条闭环

项目当前应优先完成以下闭环：

```text
v2 PIT 数据集
-> tradeable panel
-> 基础传统因子
-> 未来收益标签
-> 单因子 IC / 分组收益
-> 简单多因子打分
-> Top-N 组合回测
-> 研究日志
```

在这条闭环跑通之前，不优先引入复杂模型架构。

## 边界

- v2 Baostock PIT 快照是默认状态主源。
- v1 TDX 仅作为当前有效股票池历史回看或后续行情交叉校验来源。
- `daily_research` 不属于本研究框架的写入范围。
- 大型原始数据、缓存和快照继续保存在 ignored 的 `traditional_quant_research/data/raw/` 下。
