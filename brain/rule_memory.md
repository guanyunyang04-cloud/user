# 主脑规则记忆

快照日期：`2026-04-12`

## 1. 宪法级规则
- `Agent 无状态，项目大脑有状态。`
- 关键状态必须外显，不得依赖单个 agent 的隐性上下文。
- 接管必须 `brain-first`。
- 生产型分脑默认遵守“收益优先、非降级”，不得静默改写。
- 事实、推断、假设必须分离。

## 2. 策略级规则
- 默认接管顺序：
  - `identity -> handoff packet -> rule -> lesson -> temporal -> working -> procedural`
- 跨项目规则先写主脑，再写分脑。
- 结构变更先改架构，再改 manifest，再改内容，再跑守卫。

## 3. 经验级规则
- 新脑区如果不进 manifest 和守卫，就等于没接入。
- 接管质量最怕的不是信息少，而是没有标准状态包。
- `episodic_memory` 适合作为证据库，不适合作为默认第一入口。
