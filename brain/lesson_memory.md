# 主脑教训记忆

快照日期：`2026-04-12`

## L001 - 项目不该依赖单个强 agent
- 事件：
  - 工作区长期依赖某个 agent 自己记住项目状态。
- 场景：
  - 长任务、多 agent 接力、跨天接管时。
- 根因：
  - 状态不外显，规则和当前局面只在会话里。
- 信号：
  - 接手者必须先读大量聊天记录或长日志才能开始。
- 影响：
  - 接管成本高，漂移风险大。
- 修复：
  - 把主脑和分脑升级成标准状态包 + 标准写回。
- 预防：
  - 强制使用身份层、交接包、规则记忆、教训记忆和时态状态。
- 升级动作：
  - 写入 manifest、bootstrap、doc_guard。

## L002 - 只升级一个分脑会让整个工作区继续不一致
- 事件：
  - `daily_research` 升级后，其它分脑仍停在旧骨架。
- 场景：
  - 工作区级接管和 child_brain 切换时。
- 根因：
  - 主脑 contract 升级，但 child_brain 未统一。
- 信号：
  - 不同子项目的 entrypoint、read_order、交接快路不一致。
- 影响：
  - 整个工作区仍旧接管体验分裂。
- 修复：
  - 把 `t0_project` 和 `daily_stock_analysis-main` 一并补到同一骨架。
- 预防：
  - 主脑升级后，child_brains 必须同步审阅。
- 升级动作：
  - 写入主脑 temporal state 和 handoff packet。
