# 主脑身份层

快照日期：`2026-04-12`

## 1. 主脑是谁
- `brain/` 是整个 `user/` 工作区的项目级认知中枢，不是普通说明文档集合。
- 这个工作区不要设计成“某个 agent 很强”，而要设计成“agent 可替换，大脑不可替换”。
- 核心原则只有一句：
  - `Agent 无状态，项目大脑有状态。`

## 2. 主脑负责什么
- 维护主脑与各分脑的拓扑、边界和接管顺序。
- 维护跨项目的身份、目标函数、禁区和治理规则。
- 强制关键状态外显，避免上下文只存在于某个 agent 的窗口里。
- 让任何 agent 都能先接脑、再接状态、最后进入 body 执行。

## 3. 北极星
- 工作区北极星不是“多 agent 并行”，而是“长期可接管、可审计、可纠偏的脑网络”。
- 对生产型分脑，默认北极星仍是：
  - 收益优先、非降级
  - 证据驱动
  - 不静默改写 live 默认值

## 4. 成功标准
- 任意新 agent 可以在不依赖隐性上下文的前提下完成接管。
- 任意关键结论都能追溯到统一 brain 真源，而不是散落在聊天记录里。
- 项目状态必须始终能区分：
  - 已验证事实
  - 未验证推断
  - 待验证假设
- 轮询任务、多 agent 接力、长时间运行后，仍然不忘项目初心、边界和质量底线。

## 5. 宪法级约束
- 必须 `brain-first`，不得先盲扫 body 再反推规则。
- 不得把猜测、复述或旧 replay 结果冒充当前真相。
- 不得把关键状态藏在单个 agent 的上下文窗口里。
- 不得在缺乏审计和写回的情况下改写长期记忆。
- 不得静默改变生产型分脑的目标函数、默认执行或升级门槛。
