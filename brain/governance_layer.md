# 主脑治理层

快照日期：`2026-04-12`

## 1. 治理目标
- 监督脑网络是否偏离目标。
- 保证关键状态、规则、计划、风险和交接信息始终外显。
- 在结构漂移、状态过期、交接失真时，强制触发修复。

## 2. 工作区级自检循环
1. `Wake`
   - 先读取身份层和交接包，不直接开干。
2. `Locate`
   - 判断当前任务属于哪个分脑、哪个阶段、哪一类问题。
3. `Pick`
   - 从候选任务里选择当前最该做的一件事。
4. `Preflight`
   - 过目标一致性、规则冲突、历史教训、依赖完整性四检。
5. `Act`
   - 执行动作并记录证据。
6. `Reflect`
   - 把结果沉淀为事实、经验、规则或教训。
7. `Replan`
   - 若结果改写路径，立刻更新接下来该做什么。

## 3. 偏移检测
- 目标偏移：
  - 做着做着忘了北极星和当前真实目标。
- 上下文偏移：
  - 拿过期状态、旧默认值或旧口径当现状。
- 行为偏移：
  - 计划清楚，但执行越来越散，写回越来越少。
- 认知偏移：
  - 把单次成功当定律，把猜测当事实，把 recent 当 promotion。

## 4. 修复分级
- 轻度偏移：
  - 刷新身份层、交接包、当前优先级。
- 中度偏移：
  - 回退到上一个稳定检查点，补审查步骤，重排计划。
- 重度偏移：
  - 冻结相关决策，清理污染记忆，要求高等级确认后再继续。

## 5. 主脑守卫
- `doc_guard.py check`
  - 检查脑文件结构、manifest 与时间序列纪律。
- `brain_bootstrap.py`
  - 统一解析主脑优先的接管顺序。
- 所有结构升级都必须满足：
  - manifest 可解析
  - read order 可执行
  - write route 可追踪
  - handoff packet 可读取

## 6. 写回纪律
- 新的长期身份、边界、禁区写回身份层或主脑。
- 新的治理规则写回治理层或程序记忆。
- 当前最高优先级写回 `brain/working_memory.md`。
- 当前交接摘要写回 `brain/handoff_packet.md`。
- 项目内部事实与证据，继续写入对应分脑，不在主脑复制一份伪真源。
