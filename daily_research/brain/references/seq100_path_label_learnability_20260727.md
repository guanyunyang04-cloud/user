# Seq100 未来路径标签可学习性审计

日期：`2026-07-27`

研究：`seq100_path_label_learnability_v1`

权威 compact record：
`daily_research/research_records/seq100/seq100_path_label_learnability_v1/artifact.json`

## 问题与边界

本研究只回答一个问题：在统一的事前输入下，`g_H`、`mfe_H`、
`pre_peak_mae_H` 与固定 K3 `state_H`，哪类未来路径标签在
D5/D10/D20/D40/D60 上更稳定地可学习。

- 样本为全 PIT 主板候选，共 8,674,588 行。
- 输入为 296 个连续特征和 5 个按训练折映射的类别特征。
- 训练/评价为扩展窗口 2023、2024、2025 三折，并按标签真实依赖期限清洗。
- 三年都已经烧为发现/评价年份，不是未触碰的最终留出集。
- 最大读取结果日为 `2025-12-31`；没有训练、筛选、校准或评价 2026。
- 本研究不选择持有期、退出规则、槽位、杠杆、止损或继任架构。

63 个 LightGBM 均完成。前台总墙钟约 8 小时 40 分，模型训练时间合计
7.74 小时；内存守卫最低可用内存 1.567 GiB。全量聚合时重新核验了每个
`task_result` 所绑定模型、预测和日度指标的大小与 SHA-256。

## 冻结规则的机械结论

冻结决策规则选择 `state_H` 为主标签，只保留 D5/D10/D20。输出语义是每个
期限的 low/mid/high 三类概率。`pre_peak_mae_H` 在 D5/D10/D20/D40 作为辅助
风险标签通过。

| 期限 | Rank IC 2023/2024/2025 | Top-5% high-state 富集 | high-state Brier skill |
|---|---|---|---|
| D5 | 0.0691 / 0.0300 / 0.0490 | 0.1262 / 0.0935 / 0.1411 | 0.0391 / 0.0450 / 0.0532 |
| D10 | 0.0746 / 0.0717 / 0.0708 | 0.1003 / 0.0864 / 0.1208 | 0.0313 / 0.0505 / 0.0489 |
| D20 | 0.0855 / 0.0812 / 0.0607 | 0.0759 / 0.0892 / 0.1001 | 0.0033 / 0.0421 / 0.0295 |

这些结果说明，现有事前信息能稳定区分短中期的低、中、高路径状态，并且
Top-5% 预测组在三年都更常进入真实 high 状态。它不意味着聚类编号本身就是
收益，也不意味着 D5/D10/D20 是交易持有期；这里只选择了需要预测的结果坐标。

`pre_peak_mae_H` 是最容易预测的标签族。D5/D10/D20 的三年 Rank IC 大约在
0.184-0.240，D40 为 0.109/0.180/0.220。它回答的是“实现机会前通常要承受多大
逆向波动”，不能单独作为上涨机会目标。

## 不能被机械结论掩盖的证据

### MFE 不是不可学

`mfe_H` 在 D5-D40 的排名和幅度富集很强：最差年 Rank IC 分别为
0.0591、0.1088、0.1426、0.0605；D20 Top-5% 的平均 MFE 相对全域提高
4.33/5.23/4.90 个百分点。

它失败的唯一共同门是“Top-5% 中 `mfe_H > 0` 的发生率也必须三年提高”。
D20 的该项反而为 -3.72/-0.57/-5.09 个百分点。这里不是模型没有找到更大的
上涨尾部，而是它把幅度集中到较少的强路径上，没有提高“至少出现一次正 MFE”
这个很宽松事件的频率。因此冻结结论不能被事后改写，但 MFE 仍是下一份合同
应重新审视的机会强度候选。

### D60 终点收益接近通过

`g_60` 的 Rank IC 为 0.2105/0.1314/0.0937，Top-5% 收益提升三年均为正，
HAC 也三年支持。它只因 2025 的十分组 Spearman 为 0.418，低于冻结阈值 0.5
而失败。D60 没有优先权，也不能据此被选择，但不能称为没有信息。

### 长期限 state 更像校准问题

D40/D60 的 state 排名 IC 三年均为正；但 raw LightGBM 概率在部分年份的
Brier skill 为负。D60 high-state Brier skill 是 -0.252/-0.018/+0.001。
这说明排序信息存在，概率数值却不可靠。后续若研究 D40/D60，必须只用训练折
拟合概率校准器，再在外年检验；本研究不能事后加校准并改判。

冻结 `decision.json` 使用了“calibrated probabilities”措辞，但本次训练并未
拟合 Platt、isotonic 或其他后校准器。D5-D20 的正 Brier skill 只证明 raw
probability 比基准有信息，不等于已经完成部署级校准。

### g10/2024 的 NaN 已解释

该单元早停在第 1 棵树，全年只有 6 个预测值，并且每个交易日内所有股票预测
完全相同。242 个日截面都没有横截面方差，所以 Rank IC 不可定义。这不是文件
损坏，也不应填成 0；冻结门把非有限 IC 判为失败是正确处理。

## 入口成交辅助任务

次日未成交事件虽然稀少，但明显可预测：2023/2024/2025 的 PR-AUC 为
0.296/0.369/0.343，ROC-AUC 为 0.891/0.944/0.915，Brier skill 为
0.183/0.204/0.219。它应作为独立的执行概率输出，不应混进未来路径标签或提前
过滤候选。

## 对“模型该学什么”的当前回答

当前最有证据的第一版输出是：

1. 分别预测 D5、D10、D20 的 low/mid/high 路径概率，而不是把 60 天整条路径
   一次性回归成一个高维向量。
2. 同时预测 D5/D10/D20/D40 的 `pre_peak_mae`，描述机会实现前的逆向风险。
3. 独立预测次日未成交概率，供执行层使用，但不以未来成交状态过滤训练候选。
4. 暂不把 `g_H` 或 `mfe_H` 写成正式继任目标。MFE 和 `g_60` 的证据足以要求
   下一份合同保留对照，而不是永久淘汰。

这仍只是标签可学习性结论，不是可交易系统结论。下一研究必须新建合同，并在
不使用 2026 的前提下决定：概率如何做训练折内校准，多期限输出怎样合成一个
入场分数，以及这些输出在真实现金、槽位和成本约束下是否产生账户价值。
