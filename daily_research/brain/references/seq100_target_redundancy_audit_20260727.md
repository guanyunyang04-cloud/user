## MFE 跨期限结论

| 期限 | 最终角色 | 关键残余 Rank IC 2023/2024/2025 | 真实上涨尾部结论 |
|---|---|---|---|
| D5 | 省略 | -0.0003 / -0.0100 / -0.0166 | 三年仍正向富集，但没有独立的广域排序信息 |
| D10 | 核心 | 0.0084 / 0.0194 / 0.0467 | 新增 D6-D10 机会三年都提供正向增量 |
| D20 | 核心 | 0.0615 / 0.0091 / 0.0263 | 留一法与新增 D11-D20 窗口都三年同向 |
| D40 | 省略 | -0.0102 / 0.0460 / -0.0995 | 2023、2025 反向，明显依赖年份状态 |

D5 的结论不是“短期上涨机会不存在”。它原始 MFE 预测有效，残差 Top-5% 在三年
仍富集真实上涨尾部；但 D10/D20/D40 分数已存在时，D5 残余 Rank IC 三年均为负，
因此不值得让第五步每个特征族都再为它训练一套模型。

D10 提供 D5 之后的新信息。对新增 D6-D10 机会的 Rank IC 为
`0.0084/0.0194/0.0467`，尾部富集三年为正。D20 的留一残余 Rank IC 为
`0.0615/0.0091/0.0263`，新增 D11-D20 窗口也保持三年正向。两者组成第一轮
特征族审计的最小机会标签集合。

D40 虽在 2024 很强，但 2023 和 2025 的留一残余及新增窗口信息都反向。当前证据
不支持把这类年份敏感性带入第一轮大规模特征筛选。

## State 相对 MFE 的残余信息

这里把每个 state 的期望状态分数对全部四个 MFE 分数做同日正交化，再检验残差
能否排序真实 high state。

| 期限 | 残余 Rank IC 2023/2024/2025 | 残余 high-state Top-5 lift | 入场特征审计角色 |
|---|---|---|---|
| D3 | 0.0266 / 0.0244 / 0.0348 | -0.0066 / -0.0043 / -0.0174 | 省略 |
| D5 | 0.0426 / 0.0284 / 0.0479 | -0.0042 / -0.0122 / -0.0228 | 省略 |
| D10 | 0.0493 / 0.0612 / 0.0778 | 0.0079 / 0.0086 / 0.0188 | 核心 |
| D20 | 0.0585 / 0.0721 / 0.0713 | 0.0138 / 0.0140 / -0.0199 | 次级 |

D3/D5 的平均序数信息不是零，但把残余分数最高的 5% 当作独立入场强势头时，
三年实际 high-state lift 全为负。机械合同因此将它们从入场前的序数特征审计中
省略。D10 的残余排序与尾部都三年同向，成为核心 state 头。D20 的排序稳定，
但 2025 尾部反向，因此只保留为次级对照。

## 为什么 D3/D5 仍不能丢掉

另一项诊断使用前序样本外年份训练 MFE-only 的多分类校准器，再加入完整 state
概率。D3 在 2024/2025 的 Brier 相对改善为 `5.02%/2.55%`，D5 为
`4.12%/1.83%`，D10 为 `3.89%/1.32%`；相应 logloss 也都改善。

这说明 D3/D5 的 low/mid/high 概率包含 MFE 幅度之外的路径类别信息。正确解释是：

```text
入场前：用 MFE D10/D20 判断上涨机会是否足够大
入场后：用已经走出的 D3/D5 路径更新延续、震荡或失败判断
```

因此 D3/D5 只是从“独立入场高状态排序头”中省略，不是被宣判为无信息。后续
买入后状态更新研究仍应保留它们。

D20 概率在 2024 改善，但在 2025 的 Brier 和 logloss 分别恶化 0.64% 和
0.50%，所以不能把当前 raw probability 当作稳定的字面概率。D20 state 只作次级
对照；正式概率仍需训练期内部时间切分或滚动校准。

## 第五步的最小输出集合

第五步特征族增量审计不再对每个候选期限平均铺开：

1. 第一轮核心标签只训练 `mfe_10` 与 `mfe_20`，保持两个独立标量输出。
2. 只有在两个核心机会头上稳定增益的特征族，才继续检查核心 `state_10`。
3. `state_20` 只是次级稳健性对照，不作为特征族通过的必要条件。
4. D3/D5 state 转入以后独立的买入后路径更新研究，不参与第一轮入场筛选。
5. D3/D5/D10/D20/D40 `pre_peak_mae_H` 本轮未重审，机械上保持原候选集合；
   只对已通过机会筛选的特征族做后续风险增量检查。

这仍不是一个共同向量损失，也没有预先合成单一入场分数。分别输出能让后续实验
明确回答每组特征究竟改善了机会幅度、路径状态还是逆向风险。
