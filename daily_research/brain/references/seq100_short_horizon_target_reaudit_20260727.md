## 研究边界

本研究只重新回答“模型该学哪种未来结果”，不选择特征扩展、退出规则、持有期、
槽位、杠杆、止损或模型架构。

- 样本是 8,674,588 个全 PIT A 股主板候选，统一使用 296 个连续事前特征和
  5 个按训练折映射的类别特征。
- 新训练仅覆盖 `g_1`，以及 D3 的 `g/mfe/pre_peak_mae/state`，合计 15 个
  LightGBM；D5-D60 的旧样本外预测只重新评价，没有重训。
- D3 路径画像和聚类选择只使用 2023 年之前的数据。2023、2024、2025 是用户
  明确授权复用的确认/决策窗口，但不是全新留出集，结论必须带着这一限制理解。
- 最大读取结果日为 `2025-12-31`。2026 的 156,376 行保持全缺失，没有任何
  2026 行、结果、筛选、校准或指标进入研究。

## D3 路径是否值得单独建模

值得。pre-2023 D1-D3 全域画像包含 6,096,195 个候选和 5,929,931 条可分配
路径。K2-K10 在 2018/2020/2021/2022 四个时间窗口自主选择的 K 为
`3/2/3/3`；固定 K3 的最低跨窗口 ARI 为 0.702494，中心最低相关为 0.997814。

固定 K3 `state_3` 与逐日 `g_3` 三分位的 NMI 只有 0.172274，ARI 为
0.108288。这说明 D3 state 保留了 D1-D2 的路径形态信息，不是把 D3 终点收益
简单切成三档。

## 入场机会主标签

修正后的 MFE 门槛不再问“未来是否至少有一次正收益”，而是检验预测能否稳定
富集更大的真实上涨尾部。结果选择 D5/D10/D20/D40 `mfe_H`：

| 期限 | Rank IC 2023/2024/2025 | Top-5% 平均 MFE 提升 | Top-5% 真实日度 MFE 顶部五分位富集 |
|---|---|---|---|
| D5 | 0.0591 / 0.0691 / 0.0968 | 0.0166 / 0.0125 / 0.0176 | 0.1938 / 0.1433 / 0.1868 |
| D10 | 0.1088 / 0.1225 / 0.1581 | 0.0298 / 0.0287 / 0.0330 | 0.2037 / 0.1641 / 0.1922 |
| D20 | 0.1426 / 0.1610 / 0.1898 | 0.0433 / 0.0523 / 0.0490 | 0.1857 / 0.1731 / 0.1692 |
| D40 | 0.0605 / 0.2050 / 0.0748 | 0.0171 / 0.0848 / 0.0409 | 0.0540 / 0.1720 / 0.0902 |

D3 MFE 因 2023 Rank IC 为 -0.0055 而失败；D60 MFE 虽有正 Rank IC，但
2024 的日度顶部五分位富集为 -0.0129，因此不保留。

当前最强回答不是“预测固定持有 H 天后的收益”，而是“预测未来 H 天内可能实现
多大的可卖上涨空间”。这正对应入场前判断上涨机会的语义，但仍不代表应持有 H 天。

## 早期路径与风险输出

`state_3/state_5/state_10` 保留为主要早期路径坐标。它们不是入场机会分数的
替代品，而是供买入后观察实际走势时更新“延续、震荡、失败”判断。

| 期限 | Rank IC 2023/2024/2025 | 顺序校准后 multiclass Brier skill |
|---|---|---|
| D3 | 0.0468 / 0.0242 / 0.0388 | 0.0503 / 0.0216 / 0.0718 |
| D5 | 0.0691 / 0.0300 / 0.0490 | 0.0416 / 0.0126 / 0.0509 |
| D10 | 0.0746 / 0.0717 / 0.0708 | 0.0314 / 0.0049 / 0.0592 |
| D20 | 0.0855 / 0.0812 / 0.0607 | 0.0179 / 0.00003 / 0.0050 |

D20 虽通过机械门，但在剔除 D3/D5/D10 分数后，残余 Rank IC 只有
0.0189/0.0394/0.0090，且 2025 残余 Top-5% lift 为 -0.0081，因此降为次级
对照，不要求第一版模型必须设置 D20 state head。

顺序温度校准后的 D3-D20 Brier skill 都为正，但前一年拟合的温度经常令下一年
结果变差。正式模型不能直接搬运一个跨年温度；应在训练期内部再做时间切分，或采用
滚动校准协议。

风险输出保留 D3/D5/D10/D20/D40 `pre_peak_mae_H`。D3 三年 Rank IC 为
0.1907/0.1933/0.2170；D5-D40 已在前序审计通过。它描述实现上涨机会前需要承受
的逆向波动，应与机会幅度分开输出。

## 终点收益的角色

`g_1` Rank IC 为 -0.0262/-0.0004/-0.0323，`g_3` 为
0.0089/0.0016/0.0239，均不支持作为短周期主标签。

`g_60` 通过修正后的标量机械门，Rank IC 为 0.2105/0.1314/0.0937，Top-5%
提升三年为正；但 2023 有 66.5% 的日期没有任何横截面分数差异，剔除
`g_5/g_10/g_20/g_40` 后 2023 残余 IC 为 -0.0382。因此它只保留为长期
挑战者和对照，不提升为当前主选股标签。

## 当前输入输出结构

第一版候选输出应保持可解释的分离结构：

1. D5/D10/D20/D40 的 `mfe_H` 标量机会幅度。
2. D3/D5/D10 的 low/mid/high 路径状态概率；D20 仅作次级对照。
3. D3/D5/D10/D20/D40 的 `pre_peak_mae_H` 标量逆向风险。
4. D60 `g_H` 仅作长期挑战者，不进入默认主分数。

现在没有证据支持把这些量预先塞进一个共同向量损失。应先分别训练并在后续特征
审计中验证每个输出的独立增量，再决定是否共享树、共享表示或合成入场分数。

## 对两阶段逻辑的回答

结果支持以下语义：

```text
入场前事前特征 -> 未来异常上涨机会幅度 -> 是否值得买入
买入后已实现 D3/D5/D10 路径 -> 延续/震荡/失败状态 -> 留下或退出
```

这里确认的是标签可学习性，不是交易经济性。尚未选择实际退出条件，也没有证明
某个槽位数、持有期或止损规则能赚钱。

## 下一项独立研究

下一合同只应对本次保留的标签做分组特征增量审计。统一基础输入不变，每次只增加
一组：最近 5-10 根完整 K 线，支撑/压力/突破/回踩与量能确认，120/180/252 日及
周月线环境，KAMA/MACD/KDJ 等传统指标，严格因果化缠论结构，以及由换手和成交价
估计的筹码代理。仍按 2023/2024/2025 分年报告增量，并继续披露这三年是复用窗口；
2026 不参与。只有稳定改善保留标签样本外指标的特征组，才进入继任模型设计。
