# Seq100 短周期目标复核：冻结前输入与合同

日期：`2026-07-27`

研究：`seq100_short_horizon_target_reaudit_v1`

## 目的

本研究不是给旧研究改判，而是用独立合同回答四个遗留问题：

1. D1/D3 是否存在可学习的短周期信息。
2. D3 路径聚类是否只是 `g_3` 的离散化。
3. MFE 在改用“真实上涨尾部富集”后是否应重新保留。
4. `g_60`、多期限 state 与概率校准是否含有独立信息。

用户明确指定 `2023-2025` 为本轮最终确认/决策窗口。科学记录同时保留
限定：这些年份已被前序研究使用，不是全新留出集。`2026` 继续完全禁止读取。

## D3 全域路径画像

只使用结果截止 `2022-12-30` 的 `6,096,195` 个候选、其中 `5,929,931`
条可分配路径，对 D1-D3 独立执行 K2-K10 和固定 K3，扩展窗口为
2018/2020/2021/2022。

- 自主 K：`3/2/3/3`，最终窗口选择 K3。
- 固定 K3 跨窗口 assignment ARI 最低 `0.702494`、均值 `0.844536`。
- 匹配中心相关性最低 `0.997814`。
- 三个状态的 D3 中位收益为 `-4.07% / +0.39% / +5.79%`。

D3 state 不是简单的终点收益三分位：

- 对全局 `g_3` 三分位，NMI `0.348572`、ARI `0.248372`。
- 对逐日横截面 `g_3` 三分位，NMI `0.172274`、ARI `0.108288`。
- 逐日三分位在 state 内的纯度仅 `54.96%`，条件熵仍为 `0.839924`。

因此 D3 K3 确实保留了 D1-D2 形态信息，可以进入可学习性检验；这不等于
它一定比标量 `g_3` 更可预测。

## D1/D3 标签

全量候选数为 `8,674,588`，新标签仍以合法次日开盘为锚：

- `g_1` 有效 `8,338,623`。
- `g_3` 与 `state_3` 有效 `8,332,519`。
- `mfe_3` 与 `pre_peak_mae_3` 有效 `8,319,539`。
- MFE 只允许 D2-D3 的 `exit_sellable` 收盘，符合 A 股 T+1。
- pre-2023 的 `5,929,931` 条 state 与 D3 atlas 逐行复算零差异。
- `2026` 的 `156,376` 行全部保持 NaN/-1。

冻结的 pre-2023 date-equal MFE q80 为：D3 `3.841%`、D5 `5.608%`、
D10 `8.930%`、D20 `14.017%`、D40 `21.849%`、D60 `28.018%`。

## 冻结评价修正

MFE 不再使用“`mfe > 0` 发生率必须提高”作为门槛。主事件改为每日真实 MFE
上 20%，检查预测 Top-5% 是否三年都富集；pre-2023 q80 只作为绝对幅度敏感性。

`g_H` 不再因单年十分组 Spearman 略低于 0.5 一票否决。新门要求三年 IC、
Top-5 lift、top-bottom spread 均为正，至少两年十分组 Spearman ≥0.5，且没有
低于 -0.2 的明显反转。

state 概率采用严格顺序校准：2023 只报告 raw；2024 的温度只用 2023 OOS
预测拟合；2025 只用 2023-2024 OOS 预测拟合。
