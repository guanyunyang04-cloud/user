上手路径

按固定顺序使用控制台，可以把误操作和无效排查降到最低。

推荐顺序：先确认环境，再做体检，然后启动任务，最后到作业页和运行时页监控与恢复。

环境
固定使用 yolos
入口
run_execution_web.py
监听地址
127.0.0.1
教程文档
{{ tutorial_markdown_path }}

第一步

启动前检查

  • 确认当前程序运行在 yolos 环境中。不要依赖当前 shell 恰好激活了什么环境。
  • 如果刚升级过环境，先执行 conda env update -f daily_research/environment.yml --prune。
  • 用体检页确认依赖、manifest、持仓和运行时目录正常。

第二步

启动控制台

conda run -n yolos python daily_research/execution/run_execution_web.py --port 8765
  • 浏览器打开 http://127.0.0.1:8765。
  • 也可以使用 python daily_research/execution/run_execution_app.py web --port 8765。

第三步

页面职责

  • 总览查看当前作业、锁状态、active manifest、最近作业和最新交易计划。
  • 任务只保留核心入口：生成交易计划、刷新默认生产链、运行连续策略协议。
  • 作业查看最近作业列表，确认状态是否从排队进入运行并最终结束。
  • 体检检查依赖、运行时、manifest、持仓和关键产物是否齐全。
  • 交易计划预览 latest_trade_plan.txt 内容。
  • 连续策略查看最新训练、评估、影子导出和组合运行时状态。
  • 模拟账户维护现金和模拟持仓，用于交易计划输入。
  • 运行时查看锁、活动线程、告警与完整 JSON 快照。
