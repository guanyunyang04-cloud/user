# Archived QDP Repair Scripts

This directory contains one-off repair scripts from the data-base construction phase.

These scripts are kept as historical evidence and emergency references only. They are not public `qdp` commands and are not part of the normal update/rebuild workflow.

Current long-lived rebuild commands live under `qdp rebuild`:

```bash
qdp rebuild 5m
qdp rebuild daily-panel
qdp rebuild valuation
qdp rebuild limit-intraday
```

Archived examples here include historical intraday zero-price repair and intraday feature repair after raw-minute cleanup.
